# Веб-инструмент

Статическая страница без сборки и без зависимостей: ванильные HTML, CSS и JS.
Данные приезжают одним файлом `data.json`, который собирается из конвейера.

## Запуск

```bash
python -m hypermm.replay_ui.export     # соберёт web/data.json
python -m http.server -d web 8000      # откроет http://localhost:8000
```

`data.json` хранится в git, чтобы страница открывалась без сырых данных;
после изменений в конвейере его нужно пересобрать.

## Что внутри

| файл | что делает |
|---|---|
| `index.html` | разметка: плитки, стакан, графики |
| `style.css` | оформление, светлая и тёмная темы |
| `app.js` | загрузка данных и отрисовка на canvas |
